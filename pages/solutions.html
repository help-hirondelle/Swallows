Solution Matrix

Type Example Measures Best for Implementation Notes
Physical design Artificial nest cups, protected facade corners, roof-edge shelters New builds and major renovations Integrate into drawings before permit submission
Nuisance mitigation Droppings boards, washable surfaces, route adjustments Occupied residential buildings Pair with recurring maintenance tasks
Communication Resident FAQ, hallway posters, project notices Multi-tenant properties Set expectations before spring return period

Implementation Checklists

Low Effort (0-3 months)

  • Install temporary droppings boards in conflict spots.
  • Publish building-level guidance for residents and caretakers.
  • Document current nest locations for future works planning.

Higher Impact (3-18 months)

  • Integrate nest modules into facade upgrades.
  • Create a district pilot with owner and municipal coordination.
  • Build a local annual monitoring and reporting process.

Selection Rule

Prefer a package of measures over a single action. Coexistence projects perform better when physical measures, communication, and governance are deployed together.
